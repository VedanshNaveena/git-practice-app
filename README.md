# Git Practice Shop

A simple three-page static web application for learning Git, GitHub, and basic software testing.

## Run locally

1. Extract the ZIP file.
2. Open the `git-practice-app` folder.
3. Double-click `index.html`.
4. Navigate using Home, Customers, and Products.

No server, database, Node.js, or Java installation is required.

## Features to test

- Navigation between pages
- Add customer validation
- Add a valid customer
- Customer search
- Product search
- Product table content

## Suggested Git practice

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

Friends can then clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

For team practice, create a branch, change the application, commit, push the branch, and open a pull request.
